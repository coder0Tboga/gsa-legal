Privacy Policy

Дата вступления в силу: 2026-08-04

GSA Video Autopost ("инструмент") — это внутренний инструмент, используемый оператором проекта ГСА (карта городских событий, Омск) для публикации коротких видеороликов о городских событиях в социальные сети (VK, Telegram, YouTube, TikTok) от имени официальных аккаунтов ГСА.

Какие данные обрабатываются

Инструмент обрабатывает только видеофайлы и текстовые описания, которые оператор ГСА сам загружает для публикации. Инструмент не собирает, не хранит и не передаёт третьим лицам персональные данные конечных зрителей опубликованных видео.

Использование API социальных сетей

Инструмент использует официальные API VK, Telegram Bot API, YouTube Data API и TikTok Content Posting API исключительно для публикации видеоконтента на аккаунтах, которыми управляет оператор ГСА. Доступ к этим API авторизуется самим оператором через OAuth и может быть отозван в любой момент в настройках соответствующей платформы.

Хранение данных

Видеофайлы и токены доступа хранятся локально на инфраструктуре оператора ГСА и не передаются сторонним сервисам, за исключением самих платформ публикации (VK, Telegram, YouTube, TikTok).
