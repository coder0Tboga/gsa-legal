GSA Video Autopost

Внутренний инструмент проекта ГСА (карта городских событий, Омск) для публикации коротких видеороликов о городских событиях в социальные сети GSA: VK, Telegram, YouTube, TikTok.

Инструмент используется только оператором проекта GSA для публикации собственного контента от имени официальных аккаунтов GSA. Он не собирает данные сторонних пользователей.
